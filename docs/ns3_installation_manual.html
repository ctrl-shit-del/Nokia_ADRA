NS-3 Network Simulator - Deployment Guide

This document outlines the official requirements and procedure for deploying the NS-3 Network Simulator on a target Linux server.

1. Hardware Requirements

To ensure stable simulation environments and prevent kernel panics during high-throughput virtual network tests, the target server must meet the following specifications:

  • CPU: Minimum 1 cores (8+ cores strongly recommended for parallel builds)
  • RAM: 2 GB minimum
  • Storage: 25 GB SSD (NVMe preferred for pcap trace writing)
  • Architecture: x86_64 or ARM64

2. Software Requirements

The following software stack is required to compile and run NS-3 correctly:

  • Operating System: Ubuntu 22.04 LTS
  • Python: Python 3.9 or higher
  • Compiler: g++ (version 9 or newer)
  • Build System: cmake and ninja-build
  • Version Control: git

3. Pre-Installation Environment Setup

Before installing NS-3 dependencies, ensure the target server's package index is up to date. Additionally, because NS-3 requires raw socket access for emulation features (e.g., FdNetDevice), you must relax the host firewall temporarily during the testing phase.

Security Notice: The following commands flush the firewall rules. Only do this in a controlled lab environment. 
sudo apt-get update
sudo apt-get upgrade -y

# Disable firewall to allow raw socket bridging
systemctl stop firewalld
iptables -F

4. Package Installation

Install the required compilation and Python dependencies using the APT package manager:

sudo apt-get install -y build-essential python3 python3-dev cmake ninja-build git g++

5. Downloading and Building NS-3

Clone the official repository and build the simulator framework using CMake and Ninja:

mkdir -p /opt/ns3
cd /opt/ns3
git clone https://gitlab.com/nsnam/ns-3-dev.git
cd ns-3-dev

# Configure the build profile
./ns3 configure --build-profile=optimized --enable-examples --enable-tests

# Build the simulator
./ns3 build

6. Validation

Run the built-in test suite to ensure the installation was successful and the physics engine is stable.

./test.py
