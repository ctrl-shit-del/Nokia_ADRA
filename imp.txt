 UI Connection Complete: Finalizing the frontend connection.


✦ I have completely refactored the web frontend (web/index.html) to connect directly to the backend logic. The static, mock data has
  been removed, and the UI is now fully interactive and functional.

  Here are the changes that were made to each tab:

   * Requirements Tab: It now dynamically fetches the available requirement profiles from the backend on load. Clicking "Extract
     Requirements" or uploading a custom manual will trigger the requirements_agent via the API and dynamically load the resulting
     requirements.json data into the table.
   * Inventory Tab: The hardcoded inputs have been replaced with real state variables. Entering your Target Host, User, and Password
     and clicking "Run Inventory" will trigger the inventory_agent over SSH to scan the host and populate the "Gap Analysis" table with
     live data from inventory.json.
   * Packages Tab: It now reads your actual inventory.json to determine what hardware warnings to show and what packages are missing.
     Clicking "Prepare Installation" triggers the packages_agent to plan the installation.
   * Installer Tab: Clicking "Run Installer" will now trigger the installer_agent API. The log view has been updated to render the live
     steps, attempts, and agent diagnoses returned by the execution, rather than static mock steps.
   * Fleet Report Tab: The mock fleet status has been replaced with a live view of the session_report.md generated by the final
     execution stage.
  You can now use the "Run" buttons throughout the interface to orchestrate the agents natively through the system!
